# Análisis Comercial B2B 📊

## Descripción
Análisis de cartera comercial B2B para identificar oportunidades de mejora en conversión, segmentación de clientes y tendencia de ventas.

## Herramientas
- **SQL Server** - Modelado y análisis de datos
- **Power BI** - Visualización y dashboard

## Estructura del proyecto
- `datos/` - Dataset sintético (clientes, pedidos, productos, prospectos)
- `sql/` - Queries SQL del análisis
- `dashboard/` - Dashboard Power BI

## Hallazgos principales
- El segmento **Grande** (28% de clientes) genera el **52% de la facturación**
- **Manufactura** es la industria más rentable con el 43.5% del total
- Tasa de conversión de prospectos: **43.3%**
- 5 clientes identificados como **Champions** (RFM) con facturación > $100.000
- Cliente en riesgo detectado: 177 días sin comprar, facturación histórica $112.439

## Análisis realizados
1. Distribución de clientes por segmento
2. Facturación por segmento e industria
3. Tasa de conversión de prospectos
4. Análisis RFM (Recency, Frequency, Monetary)
5. Segmentación de clientes: Champions, Leales, En Riesgo, Inactivos
6. Tendencia mensual de ventas
